\section*{Ownership decision (\S4)}
The dependency edge is \texttt{hymeko\_wgpu $\rightarrow$ hymeko\_core}. A \texttt{hymeko\_core} bench cannot
reach a symbol defined in \texttt{hymeko\_wgpu} without a dev-dependency cycle
(core-bench $\rightarrow$ wgpu $\rightarrow$ core). The \emph{only} location reachable by both the core
benches and wgpu's tests/benches/examples is therefore \texttt{hymeko\_core}'s own public lib API. Owner:
\texttt{hymeko\_core/src/tensor/sparse\_workload.rs}, \texttt{\#[doc(hidden)] pub mod}, minimal surface
(\texttt{Lcg}, \texttt{DegreeShape}, \texttt{SparseSpec} --- the exact three names both copies export).
Placed under \texttt{tensor/} (next to \texttt{TensorCsr}), \emph{not} in \texttt{generators.rs}: it emits a
numeric \texttt{TensorCsr<f32>}, it is not a canonical hypergraph family, so it must not mix with the
Steiner/sunflower generator semantics (\S4). Name signals ``deterministic sparse workload'', not a graph
model. No new crate, no new runtime dependency, no second RNG, no second \texttt{SparseSpec}.

\section*{Performance budget}
Fixtures bit-identical (KAT). Generator source relocated verbatim $\Rightarrow$ identical codegen; no
kernel touched. Accept: every fixture bit-identical; untouched CPU/GPU kernel timing $\le 3\%$; fixture
build $\le 3\%$; runtime allocation count non-increasing; no new per-call allocation. Report core/wgpu
rlib size delta (expected: the fixture moves out of the bench crate + wgpu rlib into the core rlib). Host
ambient may exceed the 3\% quiet target $\Rightarrow$ rest no-regression on bit-identity + codegen identity,
not on noisy wall deltas (CLAUDE.md \S3 structural-evidence allowance).
