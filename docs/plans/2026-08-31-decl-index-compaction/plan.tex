\section*{Scope}
Core-only (\texttt{hymeko/core}, base \texttt{791939b}, branch
\texttt{feat/core-decl-index-compaction}). Replace the three parallel per-declaration
maps \texttt{decl\_to\_node/edge/arc: Vec<Option<Id>>} (48 B/decl) with a single compact
\emph{storage-independent} declaration$\to$concrete-record slot. No Nagare, graph/tensor,
HNN, WGPU, generational arena, transaction API, or CBOR/IR-stream \emph{format} change.

\section*{Proof before editing (Part A/B --- done in isolation, no production edit)}
Prototype (\texttt{prototype\_ABC.rs}, \texttt{prototype\_D.rs}) at 1M decls, kind mix
40/40/20, release, median of 15:
\begin{longtable}{lrrr}\toprule
rep & B/decl & seq as\_node & random as\_node \\\midrule
A: 3$\times$\texttt{Vec<Option<Id>>} (current) & 48 & baseline & baseline \\
B: one tagged enum & 16 & $+37$--$45\%$ & $+0.6$--$2.3\%$ \\
C: sentinel index, kind from \texttt{DeclNode.kind} & 8 & \textbf{$+651$--$751\%$} & \textbf{$+90\%$} \\
D: tagged \texttt{u64} (2-bit kind $|$ index$+1$; 0=NONE) & \textbf{8} & \textbf{$-4$--$-11\%$} & \textbf{$-79\%$} \\\bottomrule
\end{longtable}
\textbf{Decision: option D.} C (the task's literal option) is rejected --- its kind-check
strides the 56-byte \texttt{DeclNode} array and destroys locality. D reaches the 8-byte
target (6$\times$) \emph{and} is faster than the current single-map lookup (an 8-byte slot
has better cache behaviour than the 16-byte \texttt{Option<Id>}). Kind is encoded in the
slot tag (like B), coherence-checked against \texttt{DeclNode.kind} so it cannot diverge
unnoticed.

\section*{Interface / invariants}
Internal storage \texttt{decl\_to\_record: Vec<u64>} is \emph{private}; the public read
contract stays the accessor API (\texttt{as\_node/as\_edge/as\_arc},
\texttt{node\_for\_decl/edge\_for\_decl/arc\_for\_decl}, \texttt{node/edge/arc},
\texttt{contains\_*}), total/Option-valued. Encoding: \texttt{0}=NONE;
\texttt{(kind<<62) | (raw+1)}. Checked write: \texttt{raw+1 < 2\^{}62} (no unchecked
truncation). No \texttt{unsafe}, no lookup allocation, no HashMap on the point-lookup path.

\section*{Serde / canonical hash (Part C)}
\texttt{canonical\_program\_hash} does \emph{not} read the maps (hashes
\texttt{decl\_nodes}+records+tree), so the hash is bit-neutral by construction. The 3-map
serde form is on the (latent) CBOR wire via \texttt{CborPayload\{ir: Ir\}}; to keep the
wire byte-identical, \texttt{Ir} uses \texttt{\#[serde(from="IrWire", into="IrWire")]}
where \texttt{IrWire} carries the legacy 3-map layout. Serialize reconstructs the 3 maps
from \texttt{decl\_to\_record}; deserialize compacts them. In-memory stays compact; the
serialize-side compat allocation is measured separately.

\section*{Test strategy (Part E)}
96 parser/lowering fixtures; frozen canonical-hash vectors; permuted-construction
invariance; every \texttt{DeclKind}; anonymous arc; empty IR; invalid/sentinel/out-of-range
ID; kind/index mismatch; missing record; wrong backlink; serde legacy/new roundtrip;
corruption rejection; clone equivalence; writer output equivalence. Dynamic sizes
0,1,2,63,64,65,1k,100k,1M. $\geq$4 fault-injection mutants (wrong kind, wrong record index,
missing record, wrong backlink), each caught by a named test, source hash restored. The
documented 57/58 drift stays visible and untouched.

\section*{Performance acceptance (Part F)}
$\leq$8 B/decl mapping; $\geq$5$\times$ reduction (measured 6$\times$); construction / point
lookup / scan / clone regression $\leq$3\% (measured: lookup improves); canonical hash +
writer output bit-identical; no new hot-path allocation; peak RSS drops on the large
workload (32 B/decl of \texttt{decl\_to\_edge}+\texttt{decl\_to\_arc} freed). A/B vs
\texttt{791939b}, alternating, A/A null, ambient load recorded.

\section*{Rollback}
Three separate commits (baseline bench / refactor / perf report) on the feature branch;
any reverts with one \texttt{git revert}. Branch isolated; never merged to main.

\section*{Risk}
Serde boundary adapter correctness (roundtrip + frozen-hash tests gate it); the checked
62-bit index bound (asserted; production decl counts $\lll 2^{62}$). Worst-case input:
$\geq$1M synthetic decls under the 16 GB cap.
