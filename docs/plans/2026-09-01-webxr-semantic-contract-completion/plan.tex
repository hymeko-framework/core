\section*{Scope}
Complete the WebXR \emph{semantic} contract on branch \texttt{feat/webxr-semantic-pow0} (no main merge).
Semantic only: no JS/WASM/session/renderer/DTO/second scene graph/asset loader/runtime handles in Ir;

\section*{Architecture (meta\_spatial + meta\_webxr, one canonical Ir)}
\texttt{meta\_spatial.hymeko}: general renderer-independent spatial semantics --- kinds
(scene, spatial\_frame, spatial\_entity, visual\_asset, appearance, semantic\_anchor, affordance, action,
input\_role) and relation \texttt{@}-hyperedges (placement, parent\_frame, appearance\_binding, anchoring,
interaction, effect); pose = numeric lists \texttt{position[x,y,z]} / \texttt{orientation[x,y,z,w]} /
\texttt{scale[sx,sy,sz]}; contract: meters, quaternion xyzw, right-handed, +X right/+Y up/-Z forward.
\texttt{meta\_webxr.hymeko}: imports meta\_spatial; session modes (inline/immersive-vr/immersive-ar),
reference spaces (viewer/local/local-floor/bounded-floor/unbounded), capabilities
(hit-test/hand-tracking/dom-overlay stable; anchors/layers draft) as required/optional/runtime-reported,
input roles, WebXR action verbs. Not a second model: both lower into the one Ir; no bridge.
